# APEXWOLT · Сварочное оборудование

Страница категории B2B-каталога APEXWOLT: инверторы MMA и полуавтоматы MIG/MAG.
Статический сайт без сборки — HTML, CSS и JavaScript.

Структура и сценарии (подкатегории, «Выбор по параметрам», сортировка, сетка/список,
«Показать ещё» и страницы, карточка товара, избранное, сравнение, заявка, подписка,
нижняя навигация на телефоне) — собственная реализация по образцу типового B2B-каталога.
Код, тексты, фото и товары — только APEXWOLT.

## Запуск локально

```bash
npx serve . -l 4180
```

Открыть http://localhost:4180. Файл `serve.json` отключает «чистые» адреса, чтобы
`product.html?id=…` не терял параметр.

## Данные

Товары берутся из каталога основного проекта (`apexwolt-b2b/dist/catalog.data.js`,
категория `svarochnye-apparaty`) и собираются в `assets/js/data.js`:

```bash
node tools/build-data.mjs ../apexwolt-b2b/dist/catalog.data.js
```

Скрипт сам разбирает характеристики (ток, сеть, ПВ, электрод/проволока, масса, функции)
для фильтров и сравнения. Новые фото кладите в `assets/img/products/` с тем же именем,
что и в исходном каталоге.

## Структура

```
index.html              категория: фильтры, сортировка, сетка/список, пагинация
product.html            карточка товара: ?id=apexwolt-7-65-05
assets/css/app.css      стили (Golos Text, белый фон, мягкое стекло, синий акцент)
assets/js/data.js       сгенерированные данные — не править руками
assets/js/store.js      избранное, сравнение (до 4), заявка — localStorage
assets/js/ui.js         шапка, поиск с подсказками, панели, подписка, подвал
assets/js/catalog.js    логика страницы категории, состояние в URL
assets/js/product.js    логика карточки товара
tools/build-data.mjs    генератор data.js
```

## Публикация на GitHub

```bash
git remote add origin https://github.com/<аккаунт>/apexwolt-welding.git
git push -u origin main
```

Для GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.

## Ограничения прототипа

- Нет backend: заявка и подписка сохраняются только в браузере и показывают демо-подтверждение.
- Цена партнёра скрыта визуально; при подключении backend закрытые цены нельзя отдавать без авторизации.
- Ссылки «Главная», «Профиль», правовые документы и другие разделы каталога ведут на
  https://apexwolt-b2b-preview.netlify.app.
- В линейке 7 моделей; подкатегорий масок, горелок и аксессуаров нет, пока у APEXWOLT нет таких товаров.
